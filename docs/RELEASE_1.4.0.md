# QFXAddonManager 1.4.0

## English

- Added separate catalogs based on the top 1,000 CurseForge projects for Retail and Forever. Installed addons can use these catalogs for categorization and to open matching native settings. Forever also has a dedicated settings launcher for DungeonsForever.
- Added a preference for opening settings when you click a card. Unadapted addons can save a registered addon command in the detail panel. Opening Blizzard Settings folds the manager into a compact bar.
- Added optional minimap button collection under Switch Settings for supported addons with a manager settings entry.
- Reuses visible card rows in long lists and defers addon scans while the manager is hidden. Power changes refresh loadability for the affected addons, and explicit Self Marker shortcuts still open settings when card auto-open is off.

## 简体中文

- 正式服和无限服分别新增基于 CurseForge 人气前 1000 个项目的目录，用于给已安装插件归类，并打开能匹配到的原生设置。无限服新增 DungeonsForever 专属设置入口。
- 新增「点击卡片打开设置」开关。未适配插件可在右栏保存已注册的插件设置命令。打开暴雪设置时，管理中心收为折叠条。
- 「开关设置」新增可选的小地图按钮收纳，适用于管理中心已有设置入口的受支持插件。
- 长列表复用可见卡片行，管理中心隐藏时延后扫描。切换电源后刷新受影响插件的可载入状态。关闭卡片自动打开后，自身定位的快捷命令仍可打开设置。

## 繁體中文

- 正式服和無限服分別新增依據 CurseForge 人氣前 1000 個專案整理的目錄，用於將已安裝插件分類，並開啟能配對的原生設定。無限服新增 DungeonsForever 專屬設定入口。
- 新增「點擊卡片開啟設定」開關。未適配插件可在右欄儲存已註冊的插件設定指令。開啟暴雪設定時，管理中心收合為折疊列。
- 「開關設定」新增可選的小地圖按鈕收納，適用於管理中心已有設定入口的受支援插件。
- 長清單重複使用可見卡片列，管理中心隱藏時延後掃描。切換電源後更新受影響插件的可載入狀態。關閉卡片自動開啟後，自身定位的快捷指令仍可開啟設定。
