# QFXAddonManager 1.4.1

## English

- Fixed replies from Whisper History in WoW: Forever. Clicking a message opens a whisper to the character's full two-part name, including names with spaces.
- Changed the default whisper alert to the bundled QFX iPhone sound. The Blizzard alert remains selectable, and other selected sounds are preserved.

## 简体中文

- 修复无限服密语记录点击无法回复的问题。点击记录会将完整的双名角色名填入密语收件人。
- 密语默认提示音改为随包提供的 QFX iPhone。仍可选择暴雪提示音，已选的其他提示音会保留。

## 繁體中文

- 修正無限服密語記錄點擊後無法回覆的問題。點擊記錄會將完整的雙名角色名稱填入密語收件人。
- 密語預設提示音改為隨附的 QFX iPhone。仍可選擇暴雪提示音，已選的其他提示音會保留。
