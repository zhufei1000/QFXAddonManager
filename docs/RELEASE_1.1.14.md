# QFXAddonManager 1.1.14

## English

- Added support for World of Warcraft: Forever (Camelot) 1.60.1 / Interface 16001 in the same package as Retail 12.x.
- Forever presents the Mythic+ slot as Dungeon mode, with Classic dungeon and raid map presets and only the nine Classic classes.
- Player Stats uses Classic rows on Forever: primary stat, Hit, critical strike, armor, dodge, parry, block and defense. Attack range uses class/form probes instead of specializations.
- Mythic+ tool modules and the Adventure Journal Sets tab are not registered on Forever; delve and keystone-only options are hidden there.
- Forever labels use short WoW terms: Dungeon / Edit Dungeon, Hit, Auto (Defense).
- Complete package includes the main addon, five load-on-demand companions and shared assets. Existing settings and SavedVariables are preserved.

## 简体中文

- 同一份包新增《魔兽世界：无限》（Forever／Camelot）1.60.1 / Interface 16001 支持，同时继续支持正式服 12.x。
- 无限下“M+”模式显示为“地下城”，使用经典地下城/团本地图预设，并只显示经典九职业。
- 无限下属性面板切换为经典属性：主属性、命中、爆击、护甲、躲闪、招架、格挡、防御；攻击距离按职业/形态探测，不依赖专精。
- 无限下不加载大秘境工具模块和冒险手册套装页；隐藏地下堡入口和仅钥石触发选项。
- 无限文案采用魔兽常用短词：Dungeon／Edit Dungeon、Hit、Auto (Defense)。
- 完整包含主包、五个按需子包及共享素材；保留现有设置与 SavedVariables。
