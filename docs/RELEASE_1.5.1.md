# QFXAddonManager 1.5.1

## English

- Restore the 1.4.1 target range monitoring implementation and remove the focus distance row following client crash reports.
- Use MEDIUM strata for the manager window to reduce overlap with other addon windows. Existing collapse behavior is unchanged.
- Move Minimap Button Manager to the header beside Open Settings on Click. Both switches use a six-pixel text gap; scale and language menus follow them. Confirmation, conflict detection and combat restrictions remain active.
- Default Player Death Alert to QFX Personal Tag Red Gold for new settings and resets. Existing image choices are preserved.
- Load the QFXSkillAlerts preset only on Retail. Forever retains native settings without offering the Retail preset or writing its saved data.

## 简体中文

- 针对客户端崩溃反馈，将目标距离监控恢复为 1.4.1 实现，移除焦点距离行。
- 主窗口层级改为 MEDIUM，减少遮挡其他插件窗口，原有折叠行为保持不变。
- “小地图按钮管理”移到顶部“点击卡片打开设置”右侧。两个开关的文字间距统一为 6 像素，缩放与语言下拉顺序跟随；保留启用确认、冲突检查及战斗限制。
- 玩家死亡播报的新配置与恢复默认使用 QFX Personal Tag Red Gold 图片，保留已有图片选择。
- QFXSkillAlerts 预设仅在正式服加载；无限服保留原生设置入口，不显示正式服预设恢复按钮，也不写入其预设存档。

## 繁體中文

- 針對客戶端崩潰回報，將目標距離監控恢復為 1.4.1 實作，移除焦點距離列。
- 主視窗層級改為 MEDIUM，減少遮擋其他插件視窗，原有摺疊行為保持不變。
- 「小地圖按鈕管理」移到頂部「點擊卡片打開設置」右側。兩個開關的文字間距統一為 6 像素，縮放與語言下拉依序排列；保留啟用確認、衝突檢查及戰鬥限制。
- 玩家死亡播報的新設定與恢復預設使用 QFX Personal Tag Red Gold 圖片，保留既有圖片選擇。
- QFXSkillAlerts 預設僅在正式服載入；無限服保留原生設定入口，不顯示正式服預設恢復按鈕，也不寫入其預設存檔。
