# QFXAddonManager 1.1.13

## English

- The Party Keystone List now hides automatically when no keystone records are available, removing the empty "No keystone found." placeholder.
- Party members' keystones remain visible when you have no keystone. The list reappears when keystone records become available.
- Unlocking the list still shows five preview rows for positioning. Status updates stop while the empty list is hidden.
- Includes the main addon, five load-on-demand companions and shared assets. Existing settings and SavedVariables are preserved.

- 队伍钥匙列表没有任何钥匙记录时自动隐藏，不再显示“未找到钥匙”占位提示。
- 自己没有钥匙时，仍正常显示已收到的队友钥匙；重新获得钥匙记录后列表自动恢复。
- 解锁定位时保留五行预览，空列表隐藏时停止状态计时器。
- 完整包含主包、五个按需子包及共享素材，保留现有设置与玩家存档。
