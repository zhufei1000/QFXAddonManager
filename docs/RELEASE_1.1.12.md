# QFXAddonManager 1.1.12

## English

- Shorter, clearer English buttons and tabs throughout the manager, built-in tools, chat bar, Whisper History and Self Marker settings.
- Load modes now use M+ / Raid / PvP / Global. Exclusion editors use Edit M+ / Edit Raid / Edit PvP / Edit Classes to distinguish editing from actual addon power.
- Clearer preset and map actions: Apply Preset applies the QFX preset; Reset List only restores the current mode's map list. Existing confirmations remain in place.
- Added tooltips for Tool Settings and Tool Toggles. English addon names continue to use native addon titles, with duplicate subtitles hidden.
- Complete package includes the main addon, five load-on-demand companions and shared assets. The shared-assets TOC is generated during packaging for CurseForge upload validation.
- No SavedVariables reset or settings migration. Existing class rules, mode lists, addon switches and custom text are preserved.
