# QFXAddonManager 1.2.0

## English

- Open Settings launches the addon's own options on Retail and Forever. QFXBeggar and QfxUI_Installer keep their dedicated pages, and built-in tools continue to use the manager's settings dock.
- The QFXSystemBar launcher calls the addon's own settings entry. The copy button beside an addon title uses the original English name in every interface language and falls back to the addon folder name.
- Reviewed the 100 most popular Forever addons on CurseForge and added 20 native settings launchers. Retail and Forever load only their own client-specific addon catalogs and adapters, alongside shared code.
- Added the Auto Quest built-in tool. It is off by default and offers separate accept and turn-in controls, Shift rules, and filters. Multiple-choice rewards and quests that cost money are left for manual handling.
- Includes the main addon, five load-on-demand companions, and shared media. Restart the game after replacing the addon files to apply the updated load rules.

## 简体中文

- 正式服与无限服的普通接管统一通过“打开设置”启动插件自带的界面。QFXBeggar 和 QfxUI_Installer 保留专属设置页，内置工具继续使用管理中心的附加设置页。
- QFXSystemBar 通过插件原生入口打开设置。右栏名称旁的复制按钮在各语言界面均复制插件原始英文名，缺少英文名时复制插件目录名。
- 核查 CurseForge 无限服人气前 100 名插件，新增 20 个原生设置入口。正式服与无限服只加载各自的专用目录数据和适配文件，共用功能继续共享。
- 新增内置工具“自动交接任务”，默认关闭。可分别设置接取和交付、Shift 操作及过滤条件，多选奖励和金币消耗由玩家手动处理。
- 发布包包含主包、五个按需子包和共享素材。替换插件文件后请重启游戏，使更新后的载入规则生效。

## 繁體中文

- 正式服與無限服的一般接管統一透過「開啟設定」啟動插件自帶的介面。QFXBeggar 和 QfxUI_Installer 保留專屬設定頁，內建工具繼續使用管理中心的附加設定頁。
- QFXSystemBar 透過插件原生入口開啟設定。右欄名稱旁的複製按鈕在各語言介面均複製插件原始英文名稱，缺少英文名稱時複製插件資料夾名稱。
- 檢查 CurseForge 無限服人氣前 100 名插件，新增 20 個原生設定入口。正式服與無限服只載入各自的專用目錄資料和適配檔案，共用功能繼續共享。
- 新增內建工具「自動交接任務」，預設關閉。可分別設定接取和交付、Shift 操作及篩選條件，多選獎勵和金幣消耗由玩家手動處理。
- 發布包包含主包、五個按需子包和共用素材。替換插件檔案後請重新啟動遊戲，使更新後的載入規則生效。
