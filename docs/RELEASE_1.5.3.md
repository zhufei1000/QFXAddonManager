# QFXAddonManager 1.5.3

## English

- Prevent unadapted addon cards and their child cards from loading game icon paths, numeric file IDs, or atlases supplied by addon metadata. Addon artwork is kept; cards without eligible artwork use the bundled question mark. Inline icons are removed from unadapted addon text.
- Clicking an unadapted card now shows details only. To run a saved settings command, click **Open Options** in the right panel. Adapted addons keep their usual icon and settings behavior.

## 简体中文

- 未适配主卡和子卡不再加载插件元数据声明的游戏原生图标路径、数字资源 ID 或图集，以降低点击卡片时客户端闪退的风险。保留插件自带图片，无可用图标时显示随包问号，并移除未适配插件文字中的内嵌图标。
- 单击未适配卡片只查看详情。要执行已保存的设置命令，请点击右栏「打开设置」。已适配插件照常显示图标和打开设置。

## 繁體中文

- 未適配主卡和子卡不再載入插件中繼資料宣告的遊戲原生圖示路徑、數字資源 ID 或圖集，以降低點擊卡片時用戶端閃退的風險。保留插件自帶圖片，沒有可用圖示時顯示隨附問號，並移除未適配插件文字中的內嵌圖示。
- 單擊未適配卡片只查看詳細資料。若要執行已儲存的設定指令，請點擊右欄「開啟設定」。已適配插件照常顯示圖示及開啟設定。
