# QFX 共享素材

此目录是 QFXAddonManager 随包维护的纯素材目录，不是独立插件，不包含 TOC、注册脚本或依赖库。

上传 ZIP 会由本体构建器生成同名 TOC 元数据声明，满足平台的顶层目录检查；声明按需载入、依赖主包，不列脚本、不注册素材、不保存数据，版本跟随主包。维护源码和整合包素材快照不保留此生成文件。游戏插件列表可能显示该素材声明条目。

素材路径始终保留为 `Interface\AddOns\QFX_SharedMedia\Media\`。声音、血条纹理、个人标签图片和共享媒体名称与独立版 1.4.0 一致，已有语音、图片和纹理设置无需改写。

注册代码位于 `QFXAddonManager/Core/SharedMedia.lua`，管理中心启动时注册；通用 LibSharedMedia 由现有库或管理中心库子包提供，不依赖打开设置界面。

本目录须与管理中心一起安装和分发。升级旧独立版时，备份后移除旧 TOC、QFX_SharedMedia.lua 与 Libs，完整保留 Media。旧独立源码只作历史回退，不再回同步到当前素材目录。

原素材来源与署名保留在 CREDITS.md。
