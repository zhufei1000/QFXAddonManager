QFXAddonManager v1.1.11

本体包含主包 QFXAddonManager 和五个按需子包：QFXAddonManager_Config、QFXAddonManager_Toolbox_Daily、QFXAddonManager_Toolbox_Combat、QFXAddonManager_Toolbox_ChatBar、QFXAddonManager_Libraries_GlowFallback。根目录 QFX_SharedMedia 是必须一起保留的纯素材目录，无独立插件入口。

QFXfocus、PetStatusAlert 和 QFXSkillAlerts 需要独立下载，管理中心保留专属适配和未安装下载卡片。QFXSkillAlerts 下载包中的主包与 QFXSkillAlerts_Config 须一起安装；使用然然语音预设需配套 RanranMedia。语音预设保留原有音频路径，新空配置首次应用预设，已有提醒和个人设置不被覆盖。

普通电源、模式切换及登录恢复仅管理主插件开关，保留子插件当前启用状态。内置小工具默认值对齐旧独立 QFXToolBox 0.52.00；QFXfocus 与 PetStatusAlert 使用各自独立默认值和存档，不继承旧小工具设置，已有个人配置不被默认值覆盖。

子插件按实际安装的模块、目录与必需依赖自动归到主插件，不再单独显示为卡片或计入未适配插件数量；新增子包与汉化补丁无需补名单。搜索子包名称／说明时显示所属主插件。内部仍扫描安装信息以确认依赖，但普通主插件电源、旧卡片及通用启停／立即载入入口均不直接操作子插件。

从旧包升级：覆盖解压不会移除已经退出分发的旧目录。当前以本包列出的六个 QFXAddonManager 家族目录为准，旧适配器／词典／媒体库及已合并功能子包不再分发。其他自有插件可自行保留和维护，专属适配继续有效。不要删除玩家 WTF／SavedVariables。

使用 /qfxam、/qfxaddons 或小地图入口打开管理中心。/qfxt 与 /qfxbox 打开内置小工具。

左侧“内置工具”仅显示内置模块；“全部插件”和其他功能分类显示适配插件／分组，并保留上述三项未安装下载卡片，底部“未适配插件”按父插件合并子包。中栏卡片一行两个，名称／图标选择说明，电源控制插件启停；启停后按提示双击“重载”。

顶部秘境、团本、PVP、全局模式：单击在主界面右栏查看地图提醒设置，双击按模式标记启停并重载。秘境／团本／PVP选择开关用于编辑卡片排除标记；全局手动关闭同时加三种标记，手动开启同时清除。副本／PVP模式内电源可临时调整，下次应用模式恢复按标记启停。地图提醒默认关闭，填写地图ID并开启后仅提醒，确认才切换；已经处于对应模式时不重复提醒。地图列表可增加条目或恢复预设，底部地图名称与ID可复制。

地图提醒选择“暂时不切换”、关闭或 Esc 后，本次副本内换层、团灭复活和跑尸返回不再重复提醒；正常离开再进入后重新提醒。忽略记录仅保留当前会话，重载或重新登录会重新判断。开启“职业启用”后右键卡片选择职业并保存；关闭职业编辑仍保留已保存规则。

顶部“参数设置”集中 CVar 预设、伤害数字、延时容限和地图入口，在右侧附加设置页显示。“开关设置”在右侧说明栏集中显示开关项。选中有设置的普通模块会自动打开附加页；附加页可单独关闭。搜索同时匹配名称、说明与自定义关键词。顶部可调整界面缩放，语言下拉支持自适应／简体中文／繁體中文／English，选择后经重载生效。

主窗口、共享工厂、设置宿主、适配器与预设均由 QFXAddonManager_Config 按需提供。功能包按启用状态／设置请求加载，三语词典与通用 LibSharedMedia-3.0 已内置主包。QFX_SharedMedia 素材由主包启动注册，原名称和媒体路径不变。QFXAddonManager_Libraries_GlowFallback 在发光回退需要时加载。

请完整保留当前包中的六个 QFXAddonManager 家族目录和 QFX_SharedMedia 素材目录。首次增加子包后重新启动游戏，让客户端识别新目录。QFXToolBox 纯数据迁移桥已退出本体与整合包分发；运行继续使用 QFXAddonManagerToolboxDB／QFXAddonManagerToolboxNS。

保留旧独立小工具兼容：检测 QFXToolBox／QFXToolBox_*，只停用旧功能主插件，不改子插件开关。已有迁移回执与已安装纯数据桥继续兼容；新旧设置并存时可选择使用旧设置或保留当前设置，稍后和关闭不作选择，迁移前保留备份。核验保存成功后才提示手动清理旧目录；读取失败时不提示删除。默认值和现有个人设置保留，不删除玩家 WTF／SavedVariables。

密语记录新配置默认在会话内保留 300 条，可在设置中开启跨会话保存；已有保存记录和自定义上限保持兼容。减少动态效果后界面静态显示。

登录自动提示按重要程度逐个显示：旧小工具迁移、首次设置、语音提醒、版本说明、载入器。关闭当前提示后继续；战斗中或管理中心／游戏确认弹窗打开时等待。小工具提示和管理中心保留拖动功能。

普通插件右栏已移除主插件“启用插件”开关，主插件启停仅保留中间栏电源。右栏顺序为设置按钮、子插件小卡片、说明、插件信息和自定义搜索；只在有真实预设时显示恢复默认按钮，没有已安装子插件时整块隐藏子插件区域。子卡独立显示名称、图标、状态和电源；只有手动点击该电源才修改指定子包，不连带主插件或其他子包，不随四种模式和登录恢复而改动，修改后按提示重载。管理中心及受保护子包不可关闭，内部设置页的普通功能开关不变。
